**功能分支**: `002-cli-shell`

**创建日期**: 2026-06-02

**状态**: 草稿

**输入**: 用户描述: "CLI交互壳 (cli/) — 用户入口模块"

## 用户场景与测试 *(必填)*

### 用户故事 1 - 对话交互 (优先级: P1)

用户在终端输入 `friday` 进入交互模式，看到一个欢迎界面和提示符。用户输入自然语言提问，Friday 实时流式返回回复。用户可以连续对话，上下文在会话内保持。

**优先级理由**: 这是 Friday 最核心的交互方式，没有交互模式就没有用户价值。

**独立测试**: 启动 `friday`，输入任意问题，验证能收到流式回复，输入 exit 退出。

**验收场景**:

1. **当** 终端运行 `friday`，**那么** 显示欢迎信息并进入交互提示符，等待用户输入
2. **当** 用户输入自然语言问题，**那么** Friday 流式返回 AI 回复，回复完成后等待下一次输入
3. **当** 用户输入 `exit` 或 `quit`，**那么** 保存会话并退出交互模式

---

### 用户故事 2 - 单次执行 (优先级: P1)

用户在终端输入 `friday "帮我查一下今天的天气"` 快速获取单次回复，无需进入交互模式。执行完毕后自动退出。

**优先级理由**: 单次执行是高频快捷操作，与交互模式同等重要，适合脚本集成和快速提问。

**独立测试**: 运行 `friday "你好"`，验证输出回复后自动退出。

**验收场景**:

1. **当** 运行 `friday "某个问题"`，**那么** 输出 AI 回复后程序自动退出
2. **当** 运行 `friday "某个问题"` 且 LLM 不可用，**那么** 显示友好错误信息并以非零状态码退出

---

### 用户故事 3 - 斜杠命令 (优先级: P2)

用户在交互模式中输入 `/help` 查看可用命令列表，输入 `/save` 手动保存会话，输入 `/history` 查看历史会话。斜杠命令是结构化操作入口，与自然语言互补。

**优先级理由**: 斜杠命令提供确定性操作入口，但自然语言是主要交互方式，所以优先级略低。

**独立测试**: 进入交互模式，输入 `/help`，验证显示命令列表；输入 `/save`，验证会话被保存。

**验收场景**:

1. **当** 用户输入 `/help`，**那么** 显示所有可用斜杠命令及其简要说明
2. **当** 用户输入 `/save`，**那么** 当前会话被保存，显示保存成功提示
3. **当** 用户输入未知斜杠命令（如 `/unknown`），**那么** 提示该命令不存在并建议使用 `/help` 查看

---

### 用户故事 4 - 会话管理 (优先级: P3)

用户在交互模式中可以 `/save` 保存当前对话，下次启动 Friday 时 `/history` 列出历史会话，选择一个恢复继续对话。

**优先级理由**: 会话持久化增强连续性体验，但首次使用时用户更关注即时交互。

**独立测试**: 启动 Friday，进行几轮对话，`/save`，退出后重新启动，`/history` 能看到保存的会话。

**验收场景**:

1. **当** 用户输入 `/save`，**那么** 当前对话完整保存到本地，包含时间戳
2. **当** 用户输入 `/history`，**那么** 按时间倒序显示历史会话列表（编号 + 时间 + 首句摘要）
3. **当** 用户输入 `/load <编号>`，**那么** 加载指定历史会话，用户可继续对话

---

### 边缘场景

- 用户在交互模式中按 Ctrl+C 会怎样？→ 中断当前回复（如果正在流式输出），回到提示符；连按两次退出
- 用户输入空行会怎样？→ 忽略，重新显示提示符
- 用户输入超长文本会怎样？→ 正常接受并传给 LLM 处理
- LLM 调用失败时怎样？→ 显示友好错误信息，不退出交互模式，用户可继续输入
- 没有配置 API Key 时启动会怎样？→ 显示配置引导提示

## 需求 *(必填)*

### 功能需求

- **FR-001**: 系统 MUST 支持两种启动模式：交互模式（`friday`）和单次执行模式（`friday "问题"`）
- **FR-002**: 交互模式 MUST 显示欢迎信息、Friday 名称和版本号
- **FR-003**: 交互模式 MUST 提供多行输入提示符，支持自然语言输入
- **FR-004**: 系统 MUST 将用户输入通过 LLM 适配层发送，并流式展示回复
- **FR-005**: 交互模式 MUST 支持 `/exit`、`/quit` 命令退出
- **FR-006**: 系统 MUST 支持 `/help` 命令显示可用命令列表
- **FR-007**: 系统 MUST 支持 `/save` 命令保存当前会话到本地
- **FR-008**: 系统 MUST 支持 `/history` 命令列出历史会话
- **FR-009**: 系统 MUST 支持 `/load <编号>` 命令恢复历史会话
- **FR-010**: 交互模式中 LLM 调用失败 MUST 显示友好错误信息，不退出程序
- **FR-011**: 单次执行模式 MUST 在回复完成后自动退出
- **FR-012**: 单次执行模式失败 MUST 以非零状态码退出
- **FR-013**: 系统 MUST 在 Ctrl+C 时中断当前流式输出，不退出交互模式；连续两次 Ctrl+C 退出
- **FR-014**: 系统 MUST 在未配置 API Key 时显示配置引导信息

### 关键实体

- **会话 (Session)**: 一轮完整的对话，包含多条消息、创建时间、摘要信息
- **消息 (Message)**: 单次交互记录，区分用户消息和助手回复
- **斜杠命令 (SlashCommand)**: 结构化操作指令，有名称、描述和执行逻辑

## 成功标准 *(必填)*

### 可衡量结果

- **SC-001**: 用户能在 1 秒内进入交互模式并看到提示符
- **SC-002**: 用户输入问题后，AI 回复在 2 秒内开始流式输出
- **SC-003**: 所有斜杠命令响应时间不超过 0.5 秒（不含 LLM 调用）

- **SC-005**: 首次使用的用户无需阅读文档即可完成首次对话（自然交互引导）

## 假设

- 用户在终端环境下使用 Friday，终端支持 ANSI 颜色和 Unicode
- LLM 适配层（001-llm-adapter）已完成并可调用
- 用户已安装 Python 3.11+ 和必要的运行时环境
- 会话数据存储在本地 `~/.friday/sessions/` 目录
