# 契约：CLI 斜杠命令

**功能分支**: `002-cli-shell` | **日期**: 2026-06-02

## 命令注册表

所有斜杠命令在 `slash.py` 中静态注册，映射到处理函数。

## 命令列表

### /help

| 属性     | 值                          |
|----------|-----------------------------|
| 名称     | help                        |
| 语法     | `/help`                     |
| 参数     | 无                          |
| 说明     | 显示所有可用命令及简要说明  |
| 输出     | 命令列表表格（名称 + 说明） |
| 错误     | 无                          |

### /exit, /quit

| 属性     | 值                          |
|----------|-----------------------------|
| 名称     | exit / quit                 |
| 语法     | `/exit` 或 `/quit`          |
| 参数     | 无                          |
| 说明     | 自动保存会话并退出交互模式  |
| 输出     | 退出提示                    |
| 错误     | 无                          |

### /save

| 属性     | 值                          |
|----------|-----------------------------|
| 名称     | save                        |
| 语法     | `/save`                     |
| 参数     | 无                          |
| 说明     | 保存当前会话到本地文件      |
| 输出     | 保存成功提示 + 文件路径     |
| 错误     | 目录不存在时自动创建        |

### /history

| 属性     | 值                                       |
|----------|------------------------------------------|
| 名称     | history                                  |
| 语法     | `/history`                               |
| 参数     | 无                                       |
| 说明     | 按时间倒序列出历史会话                   |
| 输出     | 编号 + 时间 + 首句摘要，每页最多 20 条  |
| 错误     | 无历史时提示"暂无保存的会话"             |

### /load

| 属性     | 值                                    |
|----------|---------------------------------------|
| 名称     | load                                  |
| 语法     | `/load <编号>`                        |
| 参数     | 编号（/history 显示的序号）           |
| 说明     | 加载指定历史会话，继续对话            |
| 输出     | 加载成功提示 + 历史消息回放           |
| 错误     | 编号不存在时提示"会话不存在"         |

## 命令分发契约

```python
# slash.py 的公共接口
def dispatch(input: str, session: Session) -> CommandResult | None

@dataclass
class CommandResult:
    should_exit: bool = False      # 是否退出 REPL
    message: str = ""              # 结果消息
```

- 输入以 `/` 开头时走命令分发
- 不以 `/` 开头时返回 None，由 REPL 发给 LLM
- 未知命令返回错误提示
