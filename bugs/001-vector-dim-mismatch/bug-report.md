# 缺陷报告: 知识库向量检索维度不匹配导致降级

**日期**: 2026-06-06 | **严重程度**: P2 | **状态**: 已验证

## 现象描述

用户在 Friday 中执行知识库搜索时，向量检索失败，系统降级为仅 FTS5 全文搜索。错误日志：
```
向量检索失败，降级为仅 FTS5: Collection expecting embedding with dimension of 1024, got 512
```

搜索结果仍能返回，但全部来自 FTS5 关键词匹配，语义检索能力丧失。

## 环境信息

- **操作系统**: macOS (Darwin 24.5.0)
- **Python 版本**: 3.13.7
- **Friday 版本**: cd477a1
- **相关依赖**: ChromaDB, sentence-transformers (bge-small-zh-v1.5, 512维)

## 复现步骤

1. 启动 Friday 交互模式
2. 输入任意搜索请求（如"知识库内容"）
3. 观察日志输出"向量检索失败，降级为仅 FTS5"

## 期望行为

向量检索正常工作，使用 512 维 embedding 进行语义搜索。

## 实际行为

向量检索因维度不匹配失败，降级为 FTS5 关键词匹配，语义搜索能力丧失。

## 影响范围

- **受影响功能**: 知识库语义检索（RAG 检索质量下降）
- **影响用户**: 所有用户（spec 010 模型切换后未重建知识库向量索引）
- **临时规避方法**: 无，需清空旧向量索引重建

## 可能原因

spec 010 切换 embedding 模型时（bge-m3 1024维 → bge-small-zh 512维），清空了 Mem0 的 ChromaDB 数据（`~/.friday-memory/`），但知识库的向量集合（`~/.friday/indexes/chroma/`）中仍保留旧的 1024 维向量数据。
