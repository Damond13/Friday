# 修复方案: 工具调用输出显示混乱

**日期**: 2026-06-07 | **缺陷来源**: [bug-report.md](./bug-report.md) | **诊断依据**: [diagnosis.md](./diagnosis.md)

## 修复策略

改进 `show_tool_call` 和 `show_tool_result` 两个函数的截断逻辑：
- `show_tool_call`：每个参数值截断到 80 字符，超长显示 `...`
- `show_tool_result`：保留换行，限制最多 3 行，总长度 200 字符，超长显示 `...`

## 长期影响评估

### 可扩展性

正面。截断逻辑作为通用策略，未来新增工具的输出也会自动适用，无需单独处理。

### 未来功能影响

正面。更好的工具输出显示为未来添加更多工具类型提供一致的 UX 基础。

### 风险

极低。仅改变显示格式，不影响工具调用的实际参数传递和结果返回。
