# 缺陷报告: 嵌入模型重复加载且延迟到首次交互时初始化

**日期**: 2026-06-06 | **严重程度**: P2 重要 | **状态**: 已验证

## 现象描述

Friday 启动时和用户发送第一条消息时，嵌入模型 `BAAI/bge-small-zh-v1.5` 各加载一次。用户发送"你好"后出现明显延迟，并伴随 FutureWarning 和 spaCy 警告，影响首次交互体验。

## 环境信息

- **操作系统**: macOS
- **Python 版本**: 3.13
- **Friday 版本**: 41581e8 (main)
- **相关依赖**: sentence-transformers, Mem0

## 复现步骤

1. 启动 Friday
2. 观察启动日志：出现 `Loading weights: 100%`（知识库嵌入模型加载）
3. 发送"你好"
4. 观察输出：再次出现模型加载相关日志（FutureWarning: get_sentence_embedding_dimension），且响应有明显延迟

## 期望行为

1. 嵌入模型只加载一次，知识库和记忆系统共享同一个模型实例
2. 所有模型初始化在启动阶段完成，用户发送第一条消息时无额外加载延迟

## 实际行为

1. 知识库系统加载一次嵌入模型（启动时 reconcile 触发）
2. Mem0 在首次用户消息时初始化，内部又加载一次同名模型
3. 虽然代码中有共享模型注入逻辑（`memory.embedding_model.model = get_shared_model()`），但注入发生在 Mem0 已加载模型之后，白浪费了一次加载

## 影响范围

- **受影响功能**: 首次交互响应速度、内存占用
- **影响用户**: 所有用户
- **临时规避方法**: 无
